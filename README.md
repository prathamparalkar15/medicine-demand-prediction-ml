# Medicine Demand Prediction Using Machine Learning

## Project Overview

This project predicts the demand for medicines using
Machine Learning techniques.

It uses historical sales information, medicine category,
month, price, and stock data to estimate future demand.

## Machine Learning Algorithms

- Linear Regression
- Random Forest Regressor

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Streamlit

## ML Concepts

- Data Preprocessing
- Exploratory Data Analysis
- Feature Encoding
- Train-Test Split
- Regression
- Model Evaluation
- Prediction

## How to Run

Install dependencies:

pip install -r requirements.txt

Generate the dataset:

python 1_dataset.py

Train the model:

python 4_train.py

Run the application:

streamlit run app.py
